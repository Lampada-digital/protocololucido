# THE LUCID PROTOCOL

**Interval 01 — Disconnection**

Um FPS de terror psicológico inspirado em F.E.A.R. e Silent Hill.

## 🎮 Como Jogar

1. Abra o jogo no navegador
2. Clique em **"INITIATE SESSION"** ou pressione qualquer tecla
3. Clique na tela para ativar o controle do mouse
4. Use **WASD** para mover
5. Use o **mouse** para olhar
6. **Espaço** para pular

## 🎯 Objetivo

Explore a instalação da Somnus Dynamics. Descubra o que aconteceu com o Subject 034.

## 🎨 Características

- **Iluminação cinematográfica** com luzes de emergência vermelhas
- **Ambiente de laboratório** com equipamentos médicos
- **Controles responsivos** de FPS
- **Atmosfera de horror** com névoa e grain de filme

## 🛠️ Tecnologias

- Three.js
- Vite
- CSS3 animations

## 📝 Nota do Designer

Este é um protótipo focado em:
- ✅ Funcionalidade básica de FPS
- ✅ Atmosfera cinematográfica
