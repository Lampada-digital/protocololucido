## 🔫 SISTEMA DE ARMAS

### Encontrando a Arma
1. Explore o laboratório
2. Vá até a **Sala de Segurança** (leste)
3. Procure a **pistola** na mesa
4. Pressione **E** para pegar

### Usando a Arma
- **Click Esquerdo** — Atirar
- **R** — Recarregar
- **Munição limitada**: 8 balas no carregador, 24 de reserva

### Dicas de Combate
- Cada bala conta — mire com cuidado
- O som do tiro pode atrair atenção (quando inimigos forem implementados)
- Recarregue em lugar seguro
- A arma tem recuo — controle o mouse

## 💀 SISTEMA DE SAÚDE

### Barra de Saúde

- **0%** — Morte

### Como Perder Saúde
- Ataques de inimigos (quando implementados)
- Quedas altas (quando implementado)
- Eventos especiais

### Como Recuperar Saúde
- Itens médicos (quando implementados)
- Checkpoints (quando implementados)

## 🧠 SISTEMA NRL

### O Que É NRL?
**Neural Reconstruction Level** — Nível de reconstrução neural

### Como Funciona
- Começa em **100%** (realidade estável)
- Diminui gradualmente com o tempo
- Afeta a percepção da realidade

### Efeitos do NRL
| NRL | Efeito |
|-----|--------|
| 100-80% | Nenhum |
| 80-60% | Luzes piscam ocasionalmente |
| 60-40% | Sons inexplicáveis, sombras |
| 40-20% | Objetos mudam, corredores distorcem |
| 20-10% | Inimigos aparecem, realidade quebra |
| 10-0% | Lucid Breach — realidade colapsa |

### Onde Ver
- Canto superior direito da tela
- Display: "NRL: XX%"

## 🎮 CONTROLES AVANÇADOS

### Sprint
- Segure **Shift** para correr
- Consome stamina
- Stamina regenera quando não está correndo
- Útil para fugir de perigo

### Agachar
- Segure **Ctrl** para agachar
- Mais lento, mas mais silencioso
- Útil para stealth (quando implementado)

### Pular
- Pressione **Espaço**
- Útil para superar obstáculos
- Gravidade realista

## 🐛 PROBLEMAS COMUNS

### "O mouse não funciona"
**Solução:** Clique na tela para ativar o pointer lock.

### "Não consigo atirar"
**Solução:** Você precisa encontrar a arma primeiro na Sala de Segurança.

### "A tela está preta"
**Solução:** Aguarde o jogo carregar. Se persistir, recarregue a página.

### "Não sei para onde ir"
**Solução:** Explore todas as salas. Leia os documentos para entender a história.
